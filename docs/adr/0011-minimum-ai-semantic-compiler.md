# ADR-0011 — Minimum-AI / Semantic Compiler Architecture

Date: 2026-09-25  
Status: Accepted

## Context

Accessibility Red Team processes heterogeneous public websites, so some stages contain semantic ambiguity. A conventional agent architecture could delegate discovery, planning, interpretation and reporting to a general-purpose LLM.

That would make the system more expensive, less reproducible, harder to test and unnecessarily dependent on model capability.

## Decision

Deterministic software owns orchestration and state transitions.

AI is used only as a bounded semantic compiler after cheaper deterministic methods have failed to resolve an ambiguity.

The escalation order is:

```text
structured data
→ deterministic rule
→ heuristic/statistical method
→ typed semantic decision
→ constrained synthesis
→ exceptional agentic escalation
```

Semantic calls MUST:

- consume bounded evidence;
- use typed output;
- choose from legal states generated by deterministic code;
- support UNKNOWN/uncertainty where appropriate;
- record model/policy/schema versions and evidence references;
- have a deterministic fallback;
- be evaluated against a non-AI baseline.

LLMs MUST NOT own:

- pipeline planning;
- crawl execution;
- URL generation;
- accessibility pass/fail for deterministic rules;
- jurisdictional requirement resolution;
- provenance;
- scan comparison;
- state transitions.

The initial MVP is built with zero mandatory LLM calls.

## Consequences

Positive:

- cheap national-scale scans;
- reproducible results;
- easier testing;
- smaller trust boundary;
- models can be swapped or removed;
- local/small models become viable;
- model outages do not stop core scanning;
- longitudinal benchmarks are less sensitive to model drift.

Negative:

- more up-front schema and orchestration work;
- some edge cases become UNKNOWN rather than receiving an improvised answer;
- semantic task boundaries and eval sets need explicit maintenance.

These are accepted trade-offs.

## Operational test

A new AI call is rejected unless its author can demonstrate that:

1. a material unresolved semantic ambiguity exists;
2. deterministic/heuristic baselines are insufficient;
3. the output space is bounded;
4. uncertainty can be represented;
5. the call materially improves an evaluated outcome.
